info Import Format Specifications

  • Mandatory Columns: First Name, Last Name, Mobile Number, Customer Type, Postal PIN Code.
  • Tax Format: GSTIN must strictly adhere to the 15-character Indian GST format. PAN must be 10 characters.
  • Batch Processing: Records are inserted in atomic database transactions of 500 rows to ensure zero memory exhaustion.
  • Duplicates: You will be able to review and select a duplicate handling strategy (Skip, Update, or Import as New) in Step 3.
